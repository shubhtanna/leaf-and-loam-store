# Leaf & Loam

Online store for Leaf & Loam, a family plant nursery near Bengaluru that delivers across India.

Built with [Nuxt](https://nuxt.com) (Vue, server-side rendering). The catalogue lives in
`server/data/catalog.ts` and is served by `server/api/*`; the cart is kept in a cookie by the
`/api/cart` endpoints.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
```

Demo store: no real orders, payments or deliveries.
